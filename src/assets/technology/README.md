# Technology artwork

These locally stored, unmodified marks identify technologies used by Anonfolio. They are not part of Anonfolio's own logo, and do not indicate sponsorship, endorsement or affiliation. Runtime icons are bundled by Vite and cached with the application; no image is loaded from a technology vendor at runtime.
